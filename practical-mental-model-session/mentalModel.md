# React Practical Mental Modal

In this challenge you will check for password strength.

**Requirements**

1. You will have an input to enter password. It should also have an eye to hide and show password.
2. Below the input, you will have a list of requirements:
    - [ ]  At least 8 characters
    - [ ]  Contains uppercase character
    - [ ]  Contains lowercase character
    - [ ]  Contains a digit
    - [ ]  Contains a special character
3. Don’t use regex for this
4. As the user is typing, you will check an item if at the current moment the user fulfills it. Ex: If a user types in an uppercase character you will check the “Contains uppercase character” item and so on. It has to be responsive in real time.
5. Have a button `Submit` that if when clicked it will clear the input and display the created password
